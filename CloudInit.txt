برای راه‌اندازی **Cloud-Init** در Proxmox VE، باید یک ماشین مجازی (VM) را با بسته Cloud-Init آماده کرده و به **قالب (Template)** تبدیل کنید. سپس با هر بار کلون کردن از این قالب، تنظیمات اولیه (شبکه، کاربر، SSH و...) به طور خودکار اعمال می‌شود. PVE برای انتقال این تنظیمات، از یک درایو CD-ROM مجازی استفاده می‌کند.

### 🛠️ گام ۱: دانلود و آماده‌سازی "ایمیج ابری"
به جای نصب دستی سیستم‌عامل، از **ایمیج‌های آماده Cloud-Init** (با فرمت `.qcow2` یا `.img`) استفاده کنید.
*   **دانلود ایمیج**: ایمیج مورد نظر (مثلاً Ubuntu یا Debian) را با `wget` در مسیر `/var/lib/vz/template/iso/` دانلود کنید.
*   **تغییر اندازه (مهم)**: ایمیج‌های ابری معمولاً کوچک هستند (۲ تا ۵ گیگابایت). قبل از import، با دستور `qemu-img resize <image-name>.img 32G` حجم آن را افزایش دهید.

### 💻 گام ۲: ایجاد VM و وارد کردن ایمیج
با دستورات زیر یک VM خالی ساخته و دیسک ایمیج را به آن متصل کنید:
```bash
# ایجاد یک VM خالی (مثلاً با شناسه 9000)
qm create 9000 --memory 2048 --net0 virtio,bridge=vmbr0

# وارد کردن ایمیج دانلود شده به استوریج (مثلاً local-lvm)
qm importdisk 9000 /var/lib/vz/template/iso/<image-name>.img local-lvm

# اتصال دیسک وارد شده به عنوان درایو SCSI (برای اوبونتو حتماً از virtio-scsi-pci استفاده کنید)
qm set 9000 --scsihw virtio-scsi-pci --scsi0 local-lvm:vm-9000-disk-1
```


### ➕ گام ۳: افزودن درایو Cloud-Init
این درایو برای تزریق تنظیمات به VM ضروری است. می‌توانید از طریق **رابط وب** (مسیر **Hardware → Add → CloudInit Drive**) یا با دستور زیر آن را اضافه کنید:
```bash
qm set 9000 --ide2 local-lvm:cloudinit
```


### ⚙️ گام ۴: تنظیمات بوت و کنسول (توصیه‌شده)
برای بوت سریع‌تر و مشاهده وضعیت راه‌اندازی، تنظیمات زیر را اعمال کنید:
*   **بوت از دیسک اصلی**: `qm set 9000 --boot c --bootdisk scsi0`
*   **فعال‌سازی کنسول سریال**: `qm set 9000 --serial0 socket --vga serial0`

### 📋 گام ۵: تبدیل به قالب (Template)
VM آماده شده را خاموش کرده و با دستور زیر به قالب تبدیل کنید تا امکان کلون‌گیری سریع فراهم شود:
```bash
qm template 9000
```


### 🚀 گام ۶: کلون و پیکربندی نهایی
از قالب خود یک VM جدید (کلون) بسازید. سپس در تب **Cloud-Init** در رابط وب (یا با دستور `qm set`) تنظیمات نهایی را وارد کنید:
*   **کاربر و رمز عبور**: نام کاربری و رمز عبور دلخواه.
*   **کلید SSH**: برای امنیت بیشتر، کلید عمومی خود را وارد کنید.
*   **تنظیمات شبکه**: IP به صورت **DHCP** یا **Static** (مثلاً `qm set <vmid> --ipconfig0 ip=10.0.10.123/24,gw=10.0.10.1`).

با استارت VM، Cloud-Init به طور خودکار تنظیمات را اعمال کرده و سیستم آماده استفاده است.

### 💡 نکته: دستورات پرکاربرد `qm`
*   **تغییر رمز/کاربر**: `qm set <vmid> --ciuser <username> --cipassword <password>`
*   **افزودن کلید SSH**: `qm set <vmid> --sshkey ~/.ssh/id_rsa.pub`
*   **تنظیم IP استاتیک**: `qm set <vmid> --ipconfig0 ip=192.168.1.50/24,gw=192.168.1.1`
*   **تنظیم DNS**: `qm set <vmid> --nameserver 8.8.8.8`
